## 过往更新记录：
v1
该网页模板工具可以制作正面及背面，网页左侧为可编辑项目的编辑烂，右侧为效果预览窗口，用户可切换正/背面预览。
正面：
1. 角色立绘：用户可自行上传角色图片，替换文件中的“角色立绘”图层，用户可以调节角色立绘的大小和位置。
2. 背景：用户可以使用调色盘工具或输入RGB值修改“正面背景”，“背面背景”，和“底部颜色”图层的颜色，提供一个默认勾选的勾选框，勾选后，“正面背景”和“背面背景”的颜色保持一致。当前模板中“正面背景”和“背面背景”为纯色，在网页工具中改成从上到下为黑色到用户选择颜色的渐变。
3. 角色名，IP名：用户可以自行修改“NAME”和“HONKAI: STARRAIL"图层的文字，同时每个图层有独立的重置按钮，点击后将图层文字重置为默认值，也就是”NAME”和“HONKAI: STARRAIL"。
4. 命途：将当前模板中前缀为“正面命途”的图层创建为一个列表，用户可以自行选择对应图标。提供一个默认勾选的勾选框，勾选后，正面命途和背面命途选择保持一致。用户可以自行上传图片，网页工具将自动将上传图片的大小调整为与模板自带的命途图片大小一致。
5. 导出烫金层：用户点击后导出一张包含“烫金层”图层组中所有可见图层的透明底纯黑色图片。
背面：
1. 顶部标题：用户可以自行修改“HONKAI: STARRAIL"图层的文字，提供重置按钮，点击后将图层文字重置为默认值，也就是“HONKAI: STARRAIL"。
2. 命途：将当前模板中前缀为“背面命途”的图层创建为一个列表，用户可以自行选择对应图标。提供一个默认勾选的勾选框，勾选后，正面命途和背面命途选择保持一致。用户可以自行上传图片，网页工具将自动将上传图片的大小调整为与模板自带的命途图片大小一致。用户可以调节角色立绘的大小和位置，点击“居中按钮，图片将被置于画布正中心。
5. 导出烫金层：用户点击后导出一张包含“背面烫金层”图层组中顶部标题图层和对应命途图层的透明底纯黑色图片。如果用户选择上传自定义命途图片，导出的烫金层将包含顶部“背面烫金层”图层组中顶部标题图层和用户上传图片的黑色版本。

提供一个默认勾选的勾选框，取消勾选后隐藏“轮廓线”图层，此时导出的图片将不包含 “轮廓线”图层。
用户可以导出制作的拍立得。
